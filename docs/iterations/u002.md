# RFC U002: Hoist fixed predictor rotary coefficients out of NPU graph replay

RFC: [U002 design](https://github.com/InferMatrixLab/qwen3-tts-rsi-engine/issues/2). Previous rejected experiment: [U001](https://github.com/InferMatrixLab/qwen3-tts-rsi-engine/issues/1).

## Problem and scope

At source revision `9f190577aa2a147c6840560a56c5996a6c4879a4`, `UniformPredictor` replays the same 15 codebook positions for every generated codec frame. Each captured step includes a rotary coefficient calculation whose positions, frequency buffer, device and dtype remain fixed. Avoid this repeated work without changing attention, sampling, batching or codec arithmetic.

U001 paired Q/K rotary remains rejected: its measured C32 tail latency failed its frozen gate. U002 starts from the unmodified upstream base and does not include that kernel. An earlier synthetic rotary-cache probe is hypothesis evidence only, not service validation.

## Design

Add opt-in CLI `--fixed-predictor-rope`, requiring continuous mode. Default behavior stays unchanged. For each predictor batch capture, compute each of the 15 coefficient pairs using the original rotary module before warmup/capture. Retain the exact position tensors and coefficient tensors with that capture. During only its warmup/capture, substitute a read-only adapter accepting the explicitly owned position objects and matching dtype/device. Restore the original module in `finally`. No arbitrary pointer-keyed cache, process-global patch, new arithmetic, or cached talker positions.

Restrict to default (non-dynamic) predictor RoPE, inference mode and evaluation models; reject unsupported configurations. Keep coefficients alive until graph reset. New batch captures compute their own values. Reject unknown positions rather than silently returning stale coefficients. Model mutation after graph capture is outside the existing graph execution contract.

Alternatives: paired Q/K kernel (previous tail failure); fixed-size predictor KV cache (prior diagnostic slowdown); copying BF16 codec output to CPU before conversion (separate transfer path); caching all rotary positions (unbounded lifetime and dynamic position risks). This iteration implements only fixed predictor coefficients.

## Frozen validation and acceptance

- One Ascend 910B3, same model `Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice`, revision `0c0e3051f131929182e2c023b9537f8b1c68adfe`, BF16, identical optimized CLI and unchanged 128-request English/Chinese corpus (SHA256 `5007716c83b29d0247b2c6291b9704c652e01a94362c19e90ea3cb34987060c7`).
- CPU unittest suite plus existing pytest suite. Dedicated A2 predictor tests: batches 1/4/16/32/64, changing embeddings and random draws, exact code/embedding agreement across graph replays, restoration and unsupported-input checks.
- Three fresh service pairs in AB/BA/AB order; C1/2/4/8/16/32/64, 128 timed requests per arm/cohort, existing warmup policy. No output truncation; all requests must reach real EOS. Preserve actual WAVs and process exits privately; publish redacted per-request hashes/timings and source manifests.
- Accuracy: exact PCM byte/hash/length/frame-count agreement for every paired request. Original WAVs must be independently read to verify hashes, stream bytes, format and duration.
- Primary hypothesis is lower small-batch overhead: C1 paired geometric mean throughput ratio >1.01, and each of its three paired ratios >1. This deliberately targets a smaller and different scope than U001's C32/C64 target; no all-cohort >5% claim.
- Every cohort: throughput geometric mean ratio >=0.97, conservative TTFA p95 ratio `max(candidate repeats)/min(control repeats)` <=1.05. Zero process failures/forced kills; source and model identities unchanged throughout.
- Any failed accuracy/gate is FAIL; missing evidence is INCONCLUSIVE. Do not tune thresholds or discard a repeat after seeing results. A failed attempt is recorded; it does not qualify for a performance PR. Successful validation leads to a signed-off commit and reviewable PR; no merge.

## Risks and evidence boundaries

Real-service benefit may be below measurement noise despite synthetic gains. Per-batch coefficients consume additional bounded device memory. Temporary module substitution assumes the existing single model-owner thread; it must be restored on exceptions and must not affect the talker or reference generation. Source snapshots identify the actual tested candidate rather than labeling both arms as the base revision. Connection details, resolved paths, endpoints and raw logs stay outside tracked/shared artifacts; redactions are explicit.

## Reproduction

The public option is `--fixed-predictor-rope`; omit it for the control. Apply the same optimized server flags listed below to both arms. Supply connection, model and endpoint values at runtime, never in tracked configuration.

```bash
python -m unittest discover -s tests -v
python -m pytest tests -q
python tools/probe_fixed_predictor_rotary.py --model "<MODEL_PATH>" --output "<PROBE_OUTPUT>"
python tools/audit_fixed_rope_campaign.py --evidence evidence/u002-fixed-predictor-rope --output "<AUDIT_REPORT>"
```

The metadata auditor recomputes recorded measurements and frozen gates; it does not perform fresh NPU inference or independently open private WAV originals. The graph probe exercises changed inputs, both embedding modes and independently owned returned outputs. Unsupported training/dynamic RoPE and adapter restoration on exceptions are covered by CPU tests.

An already captured predictor graph assumes immutable model weights/configuration, device and dtype, as before. Reload the model to change them. The adapter is installed only while the single owner thread warms and captures a batch shape; ordinary generation sees the original rotary module.

The qualified common server arguments are:

```text
--continuous --streaming --pack-qkv --max-batch-size 64
--codec-left-context 72 --codec-batch-size 4 --incremental-codec
--pack-mlp --native-kv-update --batch-prefill --prefill-per-tick 64
--text-only-rope --prewarm-codec --native-gqa --graph-embeddings
--graph-prefill --rms-norm native --fused-swiglu --native-rope
--graph-sampling --native-rope-scope predictor --triton-snake
--cache-codec-codebooks --triton-kv-update --triton-talker-rope
--prewarm-prefill --triton-cdf --bucket-prefill --direct-prompt
```

Add `--model "<MODEL_PATH>" --device "<DEVICE>" --host "<BIND_HOST>" --port "<PORT>"` at runtime. Candidate adds only `--fixed-predictor-rope`. Run the existing `qwen3_tts_engine.benchmark` against a locally bound endpoint with `--requests 128 --warmup max(2,C) --concurrency C --frame-rate 12.5 --timeout 900` for each C1/2/4/8/16/32/64. `max(2,C)` is a formula: pass its numeric value. Preserve the exact workload bytes and record each arm's actual source identity. Repeat fresh service pairs in control/candidate, candidate/control, control/candidate order. Do not treat a standalone kernel probe as this service comparison.

## Review follow-up (R1)

Enable this option only for C1–C2; at C≥4 expect no useful throughput benefit. The original three-pair campaign is bound to `890e64ecd0ede47dd395d280886688ccc3dfcfad`. Its numerical gates and original evidence remain unchanged.

Opt-in `UniformPredictor` construction now resolves and validates `reference.model.rotary_emb` before serving startup completes. Missing or wrapped structures, training and non-default RoPE raise `ValueError` during model initialization. The shared metadata-only validator does not compute coefficients or allocate NPU resources. Capture resolves and validates again as a fallback; disabled mode does not inspect the wrapper. The existing CLI combination rejection uses exit2, whereas an unsupported model configuration fails model/service startup. They are separate checks.

Constructor and service-startup regressions, real predictor graph comparisons and C1/C2 service PCM parity are recorded separately in [review R1](../../evidence/u002-review-r1/README.md). Original full-campaign performance is historical evidence for the initial optimization, not a fresh performance claim for the review revision.

Restored A2 validation for the review implementation `d22a97981976dde533c61ff63043acf3f09cfdf6` passed: unittest18, pytest75, 40 actual predictor graph comparisons, and 256 real C1/C2 request PCM pairs identical to retained originals. All 90 measured Python files remain unchanged in the evidence follow-up. See the separate restored records for exact scope; the earlier connection failure is retained and no fresh three-pair performance result is claimed.
